# Kelly Demo Wallet

A fictional Android wallet UI built with Flutter.

## Safety
This project uses mock/local data only. It does not connect to banks, cards,
payment processors, cryptocurrency networks, or real wallets. The UI is
explicitly labeled DEMO / NO REAL MONEY.

## Build
1. Install Flutter and Android Studio.
2. Run `flutter pub get`.
3. Connect an Android device or start an emulator.
4. Run `flutter run`.
5. To create an APK: `flutter build apk --release`.
